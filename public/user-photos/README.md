Coloca aqui las fotos temporales de la exposicion.

Luego agrega sus rutas en `src/gallery/catalog.js`, dentro de `temporaryPhotos`, por ejemplo:

```js
{
  id: 'foto-1',
  title: 'Foto temporal 1',
  artist: 'Archivo temporal',
  year: '2026',
  image: '/user-photos/foto-1.jpg',
  frame: '#203f48',
  accent: '#e05f3f',
  story: 'Descripcion breve para el panel lateral.'
}
```
